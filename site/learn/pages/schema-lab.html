Lab schema: the PostGIS tables

The tables the PostgreSQL labs run on: schema learn_curriculum in a database on your own computer, built by one file, learn_curriculum.sql. Set up your tools shows how to load it.

It holds the same keyed tables as the browser's schema, in PostgreSQL's types (text for VARCHAR, float8 for DOUBLE; a dataset's key is a uuid), plus the shapes the GIS modules join records to: country outlines, admin-1 areas (states and provinces) for nine countries, biomes and ecoregions, and the habitat map's classes. Every shape is a geometry in WGS 84 (SRID 4326) with a GiST index. A record's point is a generated column, computed from its longitude and latitude, so it can never disagree with them.

The view species_taxonomy

As in the browser: one row per species with its genus, family, order and class, walked up taxa. A view stores no rows, so it isn't drawn.
