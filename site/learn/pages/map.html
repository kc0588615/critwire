critwire Learn

A course in working with data: SQL, database design, GIS in SQL, spatial statistics, ETL and Power BI, taught on critwire's own open species data and a sample of open GBIF occurrence records.

Start with Foundations: four short modules of SQL that run in this browser, with nothing to install. The tracks after it build on Foundations and on each other; each module names what it needs first. Every module answers real questions with the lab data, has an exercise that checks your answer, and says how long it takes, lab and exercise included.

Each module runs on one or two tools:

  • Browser: DuckDB running in this page. Nothing to install.
  • PostgreSQL with PostGIS: a database on your own computer, loaded with the lab data. Set up your tools shows how.
  • Python: scripts and notebooks that read the same data.
  • Power BI Desktop: reports on the star schema's files (Windows only).

A record is one observation of an animal at a place and time. The course counts and maps records; it never presents them as an animal's range.
